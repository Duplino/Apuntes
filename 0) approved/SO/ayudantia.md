## Registro del sistema
Espacios del procesador donde se guarda información

- Uso general
  - Acumulador (AX)
  - Contador (CX)
  - Base (BX)
  - Datos (DX)
- Uso particular
  - Code Segment (CS)
  - Data Segment (DS)
  - Stack Segment (SS)
- Uso especifico
  - Stack Pointer (SP)
  - Instruction Pointer (IP)
  - Program Counter (PC)
  - Program Status Word (PSW)
- Uso de control
  - Memory Address Register (MAR)
  - Memory Buffer Register (MBR)
  - Instruction Register (IR)
